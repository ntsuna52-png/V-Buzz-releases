# V-Buzz (ぶいバズ) — 配布用 / Downloads

配信アーカイブから盛り上がり場面を見つけて、縦型ショート動画（9:16）を作る Windows ソフトです。
A Windows app that finds highlight moments in stream VODs and makes vertical 9:16 shorts.
